## Частые команды (на сервере)

```bash
cd /opt/stepoffaith
docker compose ps                       # состояние
docker compose logs --tail=100 sof-bot  # логи бота (sof-api - API)
docker compose restart sof-bot          # перезапуск бота
docker compose exec -T sof-api node dist/cli.js invite admin 24   # ссылка-приглашение в команду
free -m && docker stats --no-stream     # память (на сервере ~2 ГБ на все проекты)
```

Проверка, что соседи живы: `curl -s -o /dev/null -w '%{http_code}' https://159.194.205.232.sslip.io/api/v1/health` → `200`.

## Бэкап и восстановление

```bash
ls -lt /opt/stepoffaith/backups | head               # свежие дампы
# Восстановление в текущую базу (остановите бота и API, чтобы не писали):
docker compose stop sof-bot sof-api
docker compose exec -T sof-db pg_restore -U sof -d sof --clean --if-exists < backups/sof-YYYYMMDDTHHMMSSZ.dump
docker compose start sof-api sof-bot
```

Перед конференцией: включить выгрузку в Beget S3 (`S3_BUCKET`, `S3_ACCESS_KEY_ID`,
`S3_SECRET_ACCESS_KEY` в `.env`), поставить `BACKUP_INTERVAL_MINUTES=15`, один раз восстановить
дамп на чистой машине и замерить время.

## Если что-то сломалось

| Симптом | Что делать |
|---|---|
| Бот не отвечает | `docker compose logs --tail=200 sof-bot`. Ошибка 409 Conflict - где-то ещё запущен бот с тем же токеном (локально!), остановить его. Сеть до Telegram - повторы встроены, подождать. |
| Mini App не открывается | Проверить `https://sof-app…/api/health`. Если 502 - `docker compose up -d sof-web sof-api`. Если не открывается только у части людей в РФ - ограничения Telegram/сети: дать веб-билет (кнопка «Открыть в браузере») и включить сканер в браузере. |
| Сервер недоступен | Сканеры продолжают работать офлайн (отметки копятся в телефоне). Поднять сервер или восстановить из бэкапа; после появления сети сканеры сами досинхронизируются. |
| Сканер не читает QR | Яркость экрана участника на максимум; ручной ввод кода под QR; поиск по ФИО. |
| Нет интернета у сканера | Отметки сохраняются офлайн (бейдж «N не отправлено»). Не закрывать приложение до синхронизации. |
| Пропал телефон участника | Поиск по ФИО в сканере → проверить документ → отметить вручную. |
| Подозрение на передачу скриншота | Повторный скан покажет «уже отмечен HH:MM, кем». Перевыпустить билет в админке - старый код станет недействительным. |

## День конференции - чек-лист

- [ ] За день: TTL/домены проверены, бэкапы каждые 15 минут, свежий дамп скачан на ноутбук.
- [ ] Утром: `docker compose ps` - всё `Up`, health 200, память `available` > 300 МБ.
- [ ] Wi-Fi для персонала у входа + 2 LTE-роутера разных операторов; пауэрбанки.
- [ ] У каждого сканера открыт сканер, выбрана точка «Вход», локальная база загружена (статистика видна).
- [ ] Тренировочная точка отключена, основная включена.
- [ ] Распечатанный список участников по фамилиям на каждой точке входа (выгрузка из админки).
- [ ] Касса для неоплаченных - отдельно от потока входа.
- [ ] Дежурный разработчик на связи; деплои - только хотфиксы.
